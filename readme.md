<p id="readme-perex">Colors for <a href="https://icons.getbootstrap.com/">Bootstrap</a> and <a href="https://fontawesome.com/">Font Awesome</a> icons.</p>

## 📥 Installation
Install your desired icon pack:
* Bootstrap icons - see [Install](https://icons.getbootstrap.com/#install)
* Font Awesome
  - you need to have Font Awesome icons in version [4.7](https://fontawesome.com/v4.7.0/icons/) or [5](https://fontawesome.com/icons)
  - for version 5 see [Installing Font Awesome](https://fontawesome.com/how-to-use/on-the-web/setup/using-package-managers#installing-free)

Install this project via one of package managers:
* [Composer](https://getcomposer.org)
```bash
composer require hermajan/facolors
```
* [npm](https://www.npmjs.com)
```bash
npm install @hermajan/facolors
```
