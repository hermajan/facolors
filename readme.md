<p id="readme-perex">Colors for <a href="https://icons.getbootstrap.com/">Bootstrap</a> and <a href="https://fontawesome.com/">Font Awesome</a> icons.</p>

## 📥 Installation
Install this via one of package managers:
* [Composer](https://getcomposer.org) - `composer require hermajan/facolors`
* [npm](https://www.npmjs.com) - `npm i @hermajan/facolors`

## 📚 Documentation
Usage and documentation for this project is in [wiki](https://github.com/hermajan/facolors/wiki). Examples are visible on [website](https://hermajan.net/facolors).
